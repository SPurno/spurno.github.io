Summary

Preflight Auditor runs entirely inside Adobe Photoshop. It does not collect, transmit, upload, sell or share anything. It has no network access at all.

What the plugin accesses

The plugin reads the document you currently have open in Photoshop:

  • Document properties: size, resolution, colour mode, bit depth, colour profile
  • The layer stack: names, visibility, opacity, blend modes, bounds, group nesting
  • Text layer contents and point sizes
  • Placed image and smart object source file locations, and the pixel dimensions of those source files
  • Guides and artboards
  • Fonts installed on your machine, compared against the fonts your document uses

What the plugin writes

Two things, and nothing else:

  1. Settings. Your delivery target and threshold choices are saved as a JSON file in the plugin’s own data folder inside the Creative Cloud application data directory. It is never sent anywhere and never read by another plugin.
  2. Reports. Only when you press Export report and choose a location, the report is written to that location. The report contains findings, document metadata and layer names from the document you audited. Choose carefully if your layer names are sensitive.

What the plugin does not do

  • No network requests of any kind. The manifest requests no network permission, so the plugin is technically incapable of transmitting data.
  • No telemetry, analytics, crash reporting or usage measurement.
  • No account, sign-in or licence key.
  • No access to files you have not explicitly granted. Linked image files are read only to determine their pixel dimensions, and only when the document already references them.
  • No advertising.
  • No modification of your document. Every check is read-only. The plugin never edits, moves, renames or deletes a layer, and never saves over your file.
  • No advertising of third-party products.

Third-party services

None. The plugin integrates with no external service, so there is no data sharing to disclose.

Children

The plugin is a professional tool and collects no data from anyone.

Changes to this policy

Any change will be published at the URL in the plugin listing, along with an updated version number. The installed version always matches the policy version in the About dialog.
