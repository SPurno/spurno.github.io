Requirements

Confirm these before troubleshooting anything else:

  • Adobe Photoshop 24.2 or later. Older versions cannot read a text layer’s point size.
  • A document open in Photoshop. The panel audits the document you currently have open, and nothing else.
  • UXP Developer Tool, only if you are running the plugin from source for local development.

Nothing to configure

There is no network access, no companion app and no native code. The plugin needs no sign-in, no licence key and no permissions beyond the document in front of you.

Troubleshooting

The panel reports that it could not read text metrics

Reading a text layer’s point size requires Layer.textItem.characterStyle, which arrived in Photoshop 24.1–24.2. That is why 24.2 is the floor for this plugin.

On a build where those metrics are unavailable, the panel states plainly that text metrics could not be read rather than reporting a number it never measured. Update Photoshop to 24.2 or later and run the audit again.

A check produced no output. Is it broken?

No. A check that finds nothing produces no output at all. The report never pads itself with praise for correct work, so silence on a line means the document met that threshold.

The findings do not match my printer’s requirements

Findings are measured against the active delivery profile, not against a specific print shop. Your printer’s actual requirements are outside what this plugin inspects.

Every threshold is overridable in Settings, and the settings dialog warns when a value no longer matches the active profile, so a custom threshold is always visible rather than silently in effect. Proof before approving a run.

Where are my settings and reports kept?

Settings are saved as a JSON file in the plugin’s own data folder inside the Creative Cloud application data directory. They are never sent anywhere and never read by another plugin.

Reports are written only when you press Export report and choose a location. Nothing is written anywhere else.

Does the plugin change my document?

No. Every check is read-only. The plugin never edits, moves, renames or deletes a layer, and never saves over your file.

Can it upload or share my file?

No. The manifest requests no network permission, so the plugin is technically incapable of transmitting data. There is no telemetry, no analytics, no crash reporting, no account and no advertising.

The full detail sits in the Privacy Policy.

What is out of scope

Several questions have the same answer: the plugin only reports what can be measured from the document itself. The same wording appears in the About dialog and in every exported report.

Not inspected

  • Colour separations
  • Trapping, overprint and total ink coverage
  • Fonts used by rasterised or outlined text
  • Anything outside the document itself
  • Your printer’s actual requirements

A clean report is not a guarantee of correct output. Always proof before approving a run.

The complete list of what the panel does measure is in the documentation.

Before you write

Include these and the first reply can answer the question instead of asking for details:

  • Plugin version, shown in the About dialog. The installed version always matches the policy version listed there.
  • Photoshop version you are running, including the full 24.x or 25.x number.
  • Active delivery profile and any threshold you overrode in Settings.
  • The finding text exactly as the report shows it, with the measurement and threshold it quotes.

Layer names travel with reports

An exported report contains findings, document metadata and layer names from the document you audited. Redact those first if they are sensitive.
