What it checks

Effective image resolution, colour mode, type size, broken file links, blend modes that break in CMYK, bleed, artboards, hidden content and structural debris. Every finding carries a measurement, a threshold and a concrete next step.

  • 01Image resolution
  • 02Upscaled images
  • 03Broken file links
  • 04Small text
  • 05Missing fonts
  • 06Color mode
  • 07CMYK blend modes
  • 08Bit depth
  • 09Canvas size
  • 10Bleed
  • 11Guides on trim
  • 12Artboards
  • 13Empty layers
  • 14Hidden layers
  • 15Layer names
  • 16Layer count

A check that finds nothing produces no output at all. The report never pads itself with praise for correct work.

How it behaves

The panel runs entirely inside your copy of Photoshop. It reads the open document, reports what it can measure, and waits for you to export a report.
