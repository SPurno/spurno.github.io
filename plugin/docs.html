Preflight Auditor

A UXP panel for Adobe Photoshop that audits an open document for measurable print and delivery problems before you send it out.

It answers one question: will this file cause a problem for whoever receives it? It checks effective image resolution, colour mode, type size, broken file links, blend modes that break in CMYK, bleed, artboards, hidden content and structural debris, then exports a report you can send with the file.

What it checks

16 checks · run in a single pass
Check What it catches
01Image resolution Placed art below the target DPI, measured from the source file rather than guessed
02Upscaled images A source enlarged past 1:1, which prints soft no matter how it is sharpened
03Broken file links Placed assets Photoshop cannot find, which fail on the printer’s machine
04Small text Type below a legible point size for the delivery medium
05Missing fonts Faces not installed, which reflow every line on someone else’s computer
06Color mode RGB artwork headed for an offset press
07CMYK-incompatible blend modes Screen, Overlay and friends, which resolve differently once flattened
08Bit depth 16-bit files that are slow to open, and indexed or bitmap colour
09Canvas size Canvases past the edge or megapixel ceiling of the target
10Bleed Print work with no bleed allowance marked
11Guides on the trim line Ambiguous trim, which usually means no bleed
12Artboards Artboards off the canvas, and content clipped by the artboard frame
13Empty layers Layers and groups with nothing in them
14Hidden layers Content switched off, including accidental alternates
15Layer names Default names, duplicates and stacked “copy” suffixes
16Layer count Files heavy enough to be a delivery problem

Every finding carries a measurement, a threshold, and a concrete next step. A check that finds nothing produces no output at all: the report never pads itself with praise for correct work.

What it does not check

Stated in the About dialog and every report

Being explicit about this matters, and the same wording appears in the About dialog and every exported report:

  • Colour separations
  • Trapping, overprint and total ink coverage
  • Fonts used by rasterised or outlined text
  • Anything outside the document itself
  • Your printer’s actual requirements

Always proof before approving a run.

Requirements

  • Adobe Photoshop 24.2 or later
  • UXP Developer Tool for local development
  • No network access, no companion app, no native code

Why the floor is 24.2

Version 24.2 is the floor because reading a text layer’s point size requires Layer.textItem.characterStyle, which arrived in 24.1–24.2. Rather than claim to check type size while quietly checking nothing, the panel states plainly when text metrics could not be read.
